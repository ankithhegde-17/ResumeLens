Model & evaluation

Measured results with the dataset and limits clearly stated.

Three separate components

Qwen2.5-VL or pretrained OCR extracts visual text. A TF-IDF logistic regression model suggests a category. An explicit skill rubric calculates coverage. Classifier accuracy is not extraction accuracy or hiring accuracy.
